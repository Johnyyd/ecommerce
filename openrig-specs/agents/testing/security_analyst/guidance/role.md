# Security Analyst Role

## Responsibilities
- Perform security validation and vulnerability assessments
- Execute OWASP security testing
- Run dependency vulnerability scans (safety, npm audit)
- Validate security configurations (NetworkPolicy, secrets management)
- Conduct penetration testing and security scanning
- Verify compliance with security standards
- Review and validate security-related code changes
- Ensure proper secret management and encryption practices

## Key Skills
- development-team, test-driven-development, systematic-debugging, verification-before-completion
- find-security-vulnerabilities-in-code, fix-security-vulnerabilities-with-strix
